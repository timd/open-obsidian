# open-obsidian

A tiny redirect page. Chat apps only make `https://` links clickable, so this page turns an https link into an `obsidian://` link and opens the note in Obsidian.

Usage: `https://timd.github.io/open-obsidian/?file=<path/to/note>` (optional `&vault=<name>`, default `Tim`).

It contains no notes. The note path you pass is visible in the URL.
